# Contributing to Death Improvements Plus

Issues and pull requests are welcome.

## Where to report

Report problems with Death Improvements Plus (including the Paper plugin) in [this repository's issues](https://github.com/ASOwnerYT/simple-death-improvements/issues). Don't send them to the original Simple Death Improvements project; its author doesn't maintain this fork.

When reporting a bug, include:
- Platform (Fabric, NeoForge or Paper) and Minecraft version
- Death Improvements Plus version
- Your config, and steps to reproduce
- Logs or a crash report, if there is one

## Pull requests

- Keep changes focused; one fix or feature per pull request.
- Build all targets (`./gradlew buildAndCollect`, and `./gradlew -p paper build` for Paper changes) before opening it.
- Say how you tested it, and on which platform and Minecraft version.
- New config options should exist on every platform where they make sense.

## AI-assisted contributions

This fork is itself largely AI-written (see the AI disclosure in the [README](README.md)), so AI-assisted contributions are allowed, as long as you:
- Say in the pull request which parts were AI-generated.
- Have run and tested the change yourself.
- Can answer review questions about it.

## Upstream

Changes to pajic's original mod code may be worth offering to [Simple Death Improvements](https://github.com/pajicadvance/simple-death-improvements) too. Read its contribution guidelines first; it doesn't accept AI-generated contributions.
