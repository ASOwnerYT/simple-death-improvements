# Changelog

## 1.0.0

First release of Death Improvements Plus, a fork of [Simple Death Improvements](https://github.com/pajicadvance/simple-death-improvements) 1.6.1 by pajic.

- New Paper server plugin with the same features as the mod (except accessory support), for Paper 1.21.1 and newer.
- Renamed to Death Improvements Plus with the new mod id `death_improvements_plus`. Configs from Simple Death Improvements are not carried over.
- Releases are now published on GitHub.

### Included from Simple Death Improvements 1.6.1

- Fixed crash on launch on NeoForge.
